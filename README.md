# AuraFlow – Mindful Intentions

Social manifestation project. This repository contains a Vite + React app located at `app/`.

## Getting started

1. Install dependencies

```bash
cd app
npm install
```

2. Start the dev server

```bash
npm run dev
```

Then open the printed local URL.

## Scripts

- `npm run dev`: Start development server
- `npm run build`: Type-check and build for production
- `npm run preview`: Preview the production build

## Tech

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide icons
